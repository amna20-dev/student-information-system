# Student Information System

## About the Project
This project is a Student Information System developed using 8086 Assembly Language. It is designed to manage basic student academic and administrative information.

## Features
- Student Admission
- Student Information Management
- Fee Management
- Attendance Management
- Result Management
- Student Status

## Technologies Used
- 8086 Assembly Language
- DOSBox
- Assembly Development Environment

## Project Purpose
This project was developed as part of university coursework to understand assembly language programming and basic system management.
